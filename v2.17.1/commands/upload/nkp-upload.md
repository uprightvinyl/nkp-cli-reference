# `nkp upload`

```text
Upload one of [image-artifacts, telemetry]

Usage:
  nkp upload [command]

Available Commands:
  image-artifacts Upload image artifacts to remote hosts
  telemetry       Upload telemetry information to a destination

Flags:
  -h, --help   Help for upload

Global Flags:
  -v, --verbose int   Output verbosity

Use "nkp upload [command] --help" for more information about a command.
```
