# `nkp legacy`

```text
Legacy functionality that will be removed in future releases

Usage:
  nkp legacy [command]

Available Commands:
  create      Create one of [cluster, nodepool]
  update      Update one of [controlplane, nodepool]
  upgrade     Upgrade one of [addons]

Flags:
  -h, --help          Help for legacy
  -v, --verbose int   Output verbosity

Use "nkp legacy [command] --help" for more information about a command.
```
