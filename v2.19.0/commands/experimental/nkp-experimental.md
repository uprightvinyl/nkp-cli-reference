# `nkp experimental`

```text
Experimental one of [catalog, gitops]

Usage:
  nkp experimental [command]

Available Commands:
  catalog     Experimental catalog commands (release, docgen)
  gitops      commands to interact with NKP's Gitops Host

Flags:
  -h, --help   Help for experimental

Global Flags:
  -v, --verbose int   Output verbosity

Use "nkp experimental [command] --help" for more information about a command.
```
